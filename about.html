My Computing Journey

One topic I found interesting in IT111 is binary. Binary is important in computing because computers use binary numbers to represent and process information. Learning about binary helped me understand that computers use a system of 0s and 1s to work with data.

What I Learned in IT111

IT111 has introduced me to different computing concepts that help me understand how computers and technology work.

Module 1: History of Computing

Computing has evolved from early calculating devices to electronic computers and modern digital technology. Understanding this development helps me appreciate how computing technology has become part of many fields, including Information Technology and web development.

Module 2: Computer Systems

A computer system involves hardware, software, data, people, and procedures. In creating this portfolio, I use hardware such as my computer, software such as VS Code and a web browser, and procedures for writing, saving, and testing my HTML and CSS files.

Module 3: Connected World

Connected computing allows information to travel through networks and the Internet. Websites use connected systems so users can access information through web browsers.

Cybersecurity
